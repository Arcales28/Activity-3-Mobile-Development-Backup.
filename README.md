## Scenario

This program uses a Motorcycle class to manage motorcycle information, display details, and update mileage.

## OOP Concepts Used

- Class and objects
- Constructors
- Encapsulation using a private field (`_mileage`)
- Methods to access and update mileage
- List to store multiple motorcycle objects

## How to Run

Open the project folder in the terminal and run:

```bash
dart run
```
